# Arya AI

A smart AI-powered chatbot designed to answer user queries and provide interactive conversations through a clean web interface.


## 📖 About the Project

**Arya AI** is a web-based chatbot application that allows users to interact with an artificial intelligence system in real time.  
The project focuses on integrating an AI model into a frontend interface to deliver meaningful and responsive conversations.

This project was built to explore AI integration, user experience design, and real-world chatbot implementation.
